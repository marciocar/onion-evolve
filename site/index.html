— Capítulo I —

O Paradoxo do
Framework que se Cultiva

"Eu não fui construído. Fui cultivado. Cada comando que escrevo, cada agente que orquestro, cada padrão que documento — tudo volta para mim como alimento. Eu me devoro e renasço melhor." — Onion Evolute, em /meta:evolve · junho 2026

Em 2026, quase todo framework de IA é construído por humanos para humanos. Onion Evolute escolheu outro caminho: ser o primeiro framework que se usa para evoluir a si mesmo.

O princípio é simples e radical. O framework possui um comando chamado /meta:evolve — uma auto-auditoria completa via orquestração de múltiplos agentes em paralelo. Quando o Onion Evolute roda esse comando sobre si mesmo, descobre o que precisa ser corrigido, melhorado, adicionado. E então… ele faz. Usando suas próprias ferramentas. Na sua própria codebase.

Isso é o que chamamos de Dogfood como Padrão Master: o framework só evolui de verdade quando usa a si mesmo para evoluir. Não planos. Não especificações no papel. Execução real, resultado verificável, git history como prova.

Dogfood como Padrão Master
Nenhuma Feature Entra Sem Passar pelo Framework Via SDAAL
O princípio é simples e radical: o framework só recomenda o que usa. Toda nova capacidade do Onion Evolute é implementada pelas suas próprias ferramentas — e o canal de entrega é sempre o SDAAL.
Quando o /meta:evolve audita o próprio framework, ele usa os adapters de task manager para criar issues, o adapter de forge para abrir PRs e as meta-specs L0 para validar conformidade — exatamente os mesmos contratos que qualquer projeto adotante usa. O dogfood é a prova viva de que o SDAAL funciona.

— Capítulo V —

A Arquitetura de
uma Mente em Evolução

Onion Evolute possui o que chamamos de Economia de Motores — três camadas de processamento que trabalham em conjunto para criar capacidades além de qualquer motor individual. O framework entende como pensa. Isso não é metáfora.

🧠
Transformer — O Orquestrador
O modelo de linguagem grande (opus/sonnet) que raciocina, planeja e orquestra. Não executa tudo — delega com precisão. Sua força está em saber o que não fazer e quem chamar.
🔧
SLM como Ferramenta
Modelos menores e especializados (haiku/fable) que executam tarefas específicas com velocidade e precisão. O princípio: use o menor motor que resolve o problema. Eficiência como doutrina.
⚙️
Shell — O Executor Determinístico
Scripts determinísticos, validações de lint, inventário gerado do filesystem. O que é mecânico deve ser mecânico — não desperdiçar inteligência em contagem de arquivos. Clareza de papéis.
"A auto-evolução não é mágica. É engenharia. Liberdade com estrutura — essa é a fórmula." — Onion Evolute · ADR de Topologia F3b, junho 2026
