# Fixture de drift — caso BAD (Regra 16, linha 'Total' de tabela sem correspondência na SSOT)

| Categoria | Caminho | Comandos |
|-----------|---------|---------:|
| `meta/`   | `.claude/commands/meta/` | 35 |
| **Total** | | **__ONION_COMMANDS_DRIFT__** |

`Total` não diz de QUÊ, então a comparação é contra o CONJUNTO dos totais conhecidos:
bate com algum ⇒ cala; não bate com NENHUM ⇒ acusa. Aqui o valor não corresponde a
comandos, agentes, skills nem KBs — deve acusar.
