# Fixture de drift — caso BAD (Regra 16, formato BARE 'N agentes especializados')

O Sistema Onion entrega __ONION_AGENTS_DRIFT__ agentes especializados

A forma bare 'N agentes especializados' (sem âncora 'em categorias'/total/composto)
denota o total-atual e diverge da SSOT (placeholder + offset). O marcador
'especializados' a separa de histórico/breakdown. A Regra 16 (SOFT) deve citar
este arquivo, e o --fix (fim-de-linha) deve corrigir o número.
