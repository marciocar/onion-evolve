# Fixture de drift — caso GOOD (Regra 16, guarda anti-FP: 'N skills' SEM âncora)

O time tem boas __ONION_SKILLS_DRIFT__ skills de comunicação, além das técnicas.

Sem a âncora `.claude/skills/` ou 'skills de orquestração' na mesma linha, 'skills' é
ruído comum de prosa (ex.: soft skills, skills de comunicação) — mesmo com o número
divergindo da SSOT, a Regra 16 NÃO deve citar este arquivo. É o motivo de a âncora
ser OBRIGATÓRIA (a R16 é SOFT justamente pelo risco de falso-positivo em prosa).
