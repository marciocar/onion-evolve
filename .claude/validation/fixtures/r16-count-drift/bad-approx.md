# Fixture de drift — caso BAD (Regra 16, formato APROXIMADO)

Você é um especialista integrado ao ecossistema de __ONION_COMMANDS_DRIFT__+ comandos existentes.

A forma aproximada 'N+ comandos' diverge da SSOT (placeholder + offset). A Regra 16 (SOFT)
deve citar este arquivo. O fix preserva o '+', reescrevendo só o número.
