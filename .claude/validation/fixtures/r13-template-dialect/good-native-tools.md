# Template de Exemplo — Fluxo de Edição

Este template ilustra como um comando novo deve descrever suas ferramentas
disponíveis antes de invocar o agente alvo.

Ferramentas nativas do Claude Code: Read, Write, Edit, Bash, Grep, Glob,
WebSearch, WebFetch, TodoWrite.

No passo 3, write o resultado da alteração no arquivo alvo e, em seguida,
grep pelo padrão esperado para validar que a mudança foi aplicada
corretamente.
