# Template de Exemplo — Fluxo de Edição

Este template ilustra como um comando novo deve descrever suas ferramentas
disponíveis antes de invocar o agente alvo.

Ferramentas sugeridas: Read, Write, Edit, Bash, edit_file, Grep.

No passo 3, use `edit_file` para aplicar a alteração pontual no arquivo alvo
antes de prosseguir para a validação.
