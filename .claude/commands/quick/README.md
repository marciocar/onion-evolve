# ⚡ Comandos `quick/` — atalhos de uso rápido

Atalhos leves para tarefas pontuais que não exigem um workflow faseado. Use quando quiser um resultado direto a partir de um template padrão, sem orquestração de sessão.

## Comandos

| Comando | Finalidade |
|---------|-----------|
| [`/quick:analysis`](analysis.md) | Análise rápida a partir do template `common/templates/analysis-template.md`; grava o resultado em `docs/analysis/*.md`. |
