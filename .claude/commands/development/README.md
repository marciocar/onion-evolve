# ⚙️ Comandos `development/` — desenvolvimento com SDKs

Comandos da categoria **development** do Onion: fluxos especializados de desenvolvimento orientados a um SDK/plataforma específico. Use quando o trabalho exige o conhecimento de um especialista de plataforma, não o fluxo genérico de engenharia.

## Comandos

| Comando | Finalidade |
|---------|-----------|
| [`/development:runflow-dev`](runflow-dev.md) | Desenvolvimento completo com o Runflow SDK (projetos, agentes, workflows, RAG, integrações). Delega a `@runflow-specialist`. |
