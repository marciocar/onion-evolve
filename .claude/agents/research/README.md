# 🔎 Agentes `research/` — investigação multi-fonte

Agentes de **pesquisa e análise** do Onion: investigação multi-fonte, busca web e análise semântica para transformar perguntas abertas em insights acionáveis com múltiplas perspectivas.

## Agentes

| Agente | Especialidade | Quando usar |
|--------|---------------|-------------|
| [`@research-agent`](research-agent.md) | Pesquisa multi-fonte e análise semântica (web-search, análise competitiva) | Investigações complexas que exigem cruzar múltiplas fontes e perspectivas para gerar insights acionáveis |

## 🔗 Relacionados
- [`@product-agent`](../product/product-agent.md) — consome insights de pesquisa na gestão estratégica de produto
- `@storytelling-business-specialist` — usa pesquisa para construir narrativa de negócio
- [`/meta:create-knowledge-base`](../../commands/meta/create-knowledge-base.md) — materializa achados de pesquisa como knowledge base em [`docs/knowledge-base/`](../../../docs/knowledge-base/)
