# R15.3a — o efeito-gated que o Onion já enforça (sem nome)

R15.3 diz: *efeito irreversível derivado de conteúdo não-confiável cruza o gate de execução.*
Para os canais de federação (C1) e doc-bridge (C2), **isso já é verdade hoje — por construção**.
R15.3a é **puro vocabulário**: nomear guardas estruturais existentes como membros de ONION-R15.
Nenhuma linha de código muda.

| Canal | Guarda estrutural existente | String / invariante | Read-path (verificado) |
|-------|-----------------------------|---------------------|------------------------|
| **C1 — federação a2a** | `a2a-accept` transporta o registro verificado da fila para o inbox, mas **nunca aplica** | *"NUNCA aplica nada; só transporta fila→inbox"* | `.claude/utils/federation-transport/a2a-accept.sh:8` |
| **C2 — doc-bridge inbound** | `co-deliver`/`co-relay` escrevem UNTRACKED no `inbound/`, **nunca commitam** no repo alheio | *"ENTREGA-SEM-COMMIT … NUNCA commita no repo alheio"* (invariante I3) | `.claude/utils/co-evolution/co-deliver.sh:12` |

**Por que isto é R15.3 e não outra coisa:** em ambos, conteúdo externo **entra** (autônomo) mas o **efeito**
(aplicar mudança / commitar) fica **fora do alcance da sessão receptora** — só a sessão do maestro, com
contexto, o executa. É a camada de liberação intake×execução (`authorization-layers-intake-vs-execution`)
manifestada como código, no modo **estrutural** (o efeito não é *checado*, é *impossível* sem gate).

**O que R15.3a NÃO cobre (fica para R15.3b, gated):** o canal **C3 (adopt / reverse-consolidate)** lê
conteúdo de repo alheio e *pode* gerar/aplicar artefatos guiado por ele. Ali o efeito-gate ainda não é
estrutural — precisa da extensão gated (constituição + camada de liberação). Ver
`r15-untrusted-content-provenance.md` §6, linha R15.3b.

**Ganho de nomear (custo zero):** ao dar a esses dois guardas o rótulo `ONION-R15.3a`, o Onion pode
afirmar cobertura parcial de **OWASP LLM01** com read-path confirmado — sem escrever nada. É o exemplo
canônico de por que a camada Onion Guardrails é *consolidação transversal*, não código novo: metade do
valor é **reconhecer e nomear** o que o dogfood já construiu.
