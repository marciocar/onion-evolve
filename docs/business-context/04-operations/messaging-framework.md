## Value proposition núcleo

> "Contexto explícito e versionado — decisão de negócio, execução técnica e governança — como a fonte de verdade que a IA lê no ciclo todo."

## Key messages (3–5)

1. **3 dimensões peer** (produto + engenharia + **compliance**) — o whitespace.
2. **Continuidade faseada retomável** — pausar/retomar sem perder o fio.
3. **Auto-evolução / dogfood** — o organismo que aprende (moat de credibilidade).
4. **Contexto que rende** — 40%↓erro, 55%↑veloc (Anthropic), medido.

## Mensagem por audiência

| Audiência | Ângulo |
|---|---|
| **Enterprise / regulado (P4)** | governança + trilha de auditoria p/ IA-no-loop (riscos FINRA) |
| **Empresa c/ sistemas internos (P3)** | consistência + ROI + onboarding de contexto |
| **Dev solo (P5)** | continuidade e papéis que o Claude Code puro não dá |
| **Leigo / Onion Pessoal (P6)** | `[BLOQUEADO — D3]` muda promessa e linguagem inteiras; precisa branding |

## Proof points

- Efeito medido (40%/55%); dogfood + adotante de campo que corrigiu bug do core; whitespace de compliance (nenhum concorrente cobre).
